# Data files

## `zones.geojson`

Simplified outlines of the municipalities of La Habana, used to show an
approximate zone in the offers channel. Generated with
`scripts/prepare_zones.py` from the Cuba extract by Geofabrik
(`cuba-latest.osm.pbf`).
